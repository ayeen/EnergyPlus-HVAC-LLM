# HVAC Section Headers Feature

## Overview

The HVAC-LLM system now automatically adds **clear section headers and inline comments** to all generated IDF files, making it easy to identify HVAC system objects.

## What's Added

### 1. Section Header (Top of HVAC Section)

```idf
!-======================================================================
!- VRF HVAC SYSTEM SECTION - GENERATED BY HVAC-LLM
!-======================================================================
!- This section contains all HVAC equipment objects generated automatically
!- DO NOT MODIFY - Generated from user requirements
!-======================================================================
```

**Plus timestamp in combined IDF:**
```idf
!-======================================================================
!- HVAC SYSTEM SECTION - GENERATED BY HVAC-LLM
!-======================================================================
!- Generated from user request (if provided)
!- This section contains all HVAC equipment objects
!- Generation timestamp: 2025-11-12 14:35:22
!-======================================================================
```

### 2. Inline Object Comments

Each HVAC object gets a descriptive comment:

```idf
HVACTemplate:Zone:VRF,    !- HVAC: VRF Zone Terminal Unit (Indoor Unit)
    ZONE ONE,
    VRF_System_1,
    ...;

HVACTemplate:System:VRF,  !- HVAC: VRF Outdoor Condensing Unit
    VRF_System_1,
    ...;

ZoneControl:Thermostat,   !- HVAC: Zone Thermostat Control
    ZONE ONE Thermostat,
    ...;

ThermostatSetpoint:DualSetpoint,  !- HVAC: Thermostat Setpoint Schedule
    Zone ONE Thermostat Dual SP Control,
    ...;
```

### 3. Section Footer

```idf
!-======================================================================
!- END OF VRF HVAC SYSTEM SECTION
!-======================================================================
```

## Usage

### Automatic (Default)

Headers are added automatically in all pipeline runs:

```python
from src.pipeline import HVACLLMPipeline

pipeline = HVACLLMPipeline()

results = pipeline.run(
    base_idf="data/base_idfs/building_with_zones.idf",
    zones=["ZONE ONE"],
    output_name="my_vrf_system",
    user_request="Design VRF with heat recovery"
)

# Headers automatically added to:
# - outputs/generated_idfs/my_vrf_system_hvac.idf
# - outputs/generated_idfs/my_vrf_system_FINAL.idf
```

### Verification

Check if headers exist:

```python
with open("outputs/generated_idfs/my_vrf_system_hvac.idf", 'r') as f:
    content = f.read()

if "HVAC SYSTEM SECTION - GENERATED BY HVAC-LLM" in content:
    print("✅ Headers found!")
    
# Count inline comments
hvac_comment_count = content.count("!- HVAC:")
print(f"Found {hvac_comment_count} HVAC object comments")
```

## Troubleshooting

### Issue: No headers in output file

**Possible causes:**
1. Using old version of agent1_generator.py
2. Direct IDF manipulation (bypassing generator)
3. Manual edits removed headers

**Solution:**
- Re-run pipeline to regenerate with headers
- Update agent1_generator.py to latest version

### Issue: Headers appear twice

**Possible cause:**
- Running pipeline multiple times on same output

**Solution:**
- Use unique output_name for each run
- Delete old outputs before re-running

### Issue: Wrong object comments

**Possible cause:**
- New HVAC object type not in comment mapping

**Solution:**
- Add new object type to `_add_section_header()` method in agent1_generator.py
